# Niri

A keyboard-driven, scrollable Wayland compositor that forms the foundation of
the desktop.

## Highlights

- new windows occupy half the screen by default. This makes common layouts quick to create while retaining Niri's horizontally scrolling workspace.
- Vim-style directions share a consistent set of shortcuts for focusing and moving windows, columns, workspaces, and monitors.
- generous gaps, rounded and clipped window corners, soft shadows, and a translucent cyan focus ring create a clear and cohesive Dracula-inspired look.
- Waybar, the wallpaper, idle management, and removable-drive handling start with the session, providing a complete desktop immediately after login.
- Sane keybinds for the most used software while [fuzzel](../fuzzel) cover the rest.
