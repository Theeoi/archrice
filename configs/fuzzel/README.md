# Fuzzel

A compact application launcher for quickly finding and opening desktop apps.

## Screenshots
![fuzzel overview](/../_screenshots/v1.1.0/fuzzel.png)

## Highlights

- only five results are shown at once, and the window shrinks when fewer are
  available. This keeps the launcher focused and out of the way.
- a translucent Dracula-inspired palette, rounded border, and rounded selection
  match the rest of the desktop while keeping results easy to distinguish.

The launcher is opened with `Mod+Space` from the Niri configuration.
